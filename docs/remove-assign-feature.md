# 移除订单管理"分配"功能说明

## 更新内容

根据需求，已从订单管理页面移除"分配工作人员"功能。

## 修改详情

### 1. 操作列按钮调整

**修改前**：
- 待处理状态：查看、确认、**分配**、取消
- 已确认状态：查看、**分配**、取消
- 进行中状态：查看、完成
- 已完成状态：查看
- 已取消状态：查看

**修改后**：
- 待处理状态：查看、确认、取消
- 已确认状态：查看、取消
- 进行中状态：查看、完成
- 已完成状态：查看
- 已取消状态：查看

### 2. 操作列宽度优化

- **修改前**：`width="240"`
- **修改后**：`width="200"`（移除分配按钮后缩小宽度）

### 3. 代码变更

#### 3.1 移除的组件导入
```typescript
// 已注释掉
// import WorkerAssign from './components/WorkerAssign.vue'
```

#### 3.2 注释的对话框
```vue
<!-- 分配工作人员弹窗（已禁用） -->
```

#### 3.3 注释的函数
```typescript
// 分配工作人员（已禁用）
// const handleAssign = (row: AppointmentRecord) => { ... }

// 分配提交（已禁用）
// const handleAssignSubmit = () => { ... }
```

## 为什么保留代码而不是删除？

1. **可维护性**：通过注释保留代码，方便将来需要时快速恢复
2. **可追溯性**：保留原有逻辑，便于理解系统设计
3. **灵活性**：如果业务需求变更，只需取消注释即可恢复功能

## 如果将来需要恢复分配功能

只需执行以下步骤：

### 步骤1：取消组件导入注释
```typescript
import WorkerAssign from './components/WorkerAssign.vue'
```

### 步骤2：取消对话框注释
删除注释符号，恢复分配工作人员对话框

### 步骤3：取消函数注释
```typescript
const handleAssign = (row: AppointmentRecord) => {
  currentAppointment.value = { ...row }
  assignDialogVisible.value = true
}

const handleAssignSubmit = () => {
  assignDialogVisible.value = false
  loadAppointments()
}
```

### 步骤4：恢复操作按钮
在模板中添加分配按钮

### 步骤5：调整列宽
将操作列宽度改回 `width="240"`

## 影响评估

### ✅ 正面影响
- 界面更简洁
- 操作流程更清晰
- 减少管理员误操作的可能性
- 页面加载更快（少一个组件）

### ⚠️ 注意事项
- 如果订单需要指定工作人员，需要通过其他方式处理
- 现有数据库中已有的工作人员分配不受影响
- 订单详情中仍会显示已分配的工作人员信息
