# 管理端订单管理快速使用指南

## 📍 访问路径

**管理后台** → **预约服务** → **订单管理**

或直接访问：`/appointment-orders`

## 📊 页面概览

页面从上到下分为4个区域：

1. **页面标题** - 预约服务管理
2. **统计卡片** - 6个统计数据卡片
3. **筛选工具栏** - 服务类型、状态筛选、关键词搜索
4. **订单列表** - 表格展示所有订单

## 🎯 常用操作

### 1. 处理新订单（待处理状态）

```
查看待处理订单 → 点击"确认"按钮 → 点击"分配"按钮 → 选择服务人员 → 确定
```

**步骤详解**：
1. 在统计卡片看到"待处理"数量
2. 点击"预约状态"下拉框，选择"待处理"
3. 找到需要处理的订单
4. 点击"确认"按钮，确认订单
5. 点击"分配"按钮，选择合适的服务人员
6. 点击"确定分配"

### 2. 查看订单详情

**方式1**：点击订单行
**方式2**：点击"查看"按钮

### 3. 搜索订单

在搜索框输入以下任一信息：
- 用户姓名（如：张三）
- 手机号（如：138）
- 地址（如：阳光小区）

按回车或点击搜索图标

### 4. 筛选订单

**按服务类型**：
- 全部
- 家政保洁
- 维修服务
- 快递代收

**按订单状态**：
- 全部
- 待处理
- 已确认
- 进行中
- 已完成
- 已取消

### 5. 取消订单

1. 找到需要取消的订单（待处理或已确认状态）
2. 点击"取消"按钮
3. 输入取消原因（必填）
4. 点击"确认取消"

## ⚠️ 注意事项

1. **待处理订单优先处理**：尽快确认并分配
2. **取消原因必填**：取消订单时必须填写原因
3. **进行中订单不可取消**：只能点击"完成"
4. **已完成订单不可修改**：只能查看
5. **操作不可逆**：确认操作前请仔细检查

## 💡 快捷技巧

1. **快速查看待处理订单**：
   - 点击统计卡片中的"待处理"数字
   - 或在状态筛选中选择"待处理"

2. **快速批量处理**：
   - 使用筛选功能只显示待处理订单
   - 逐个确认和分配

3. **查找特定订单**：
   - 知道订单编号：直接搜索订单编号
   - 知道用户信息：搜索姓名或手机号
   - 知道地址：搜索地址关键词

4. **重置筛选**：
   - 点击"重置"按钮清空所有筛选条件
   - 返回查看所有订单

## 📱 移动端使用

- 页面响应式设计，支持手机、平板访问
- 操作按钮自动适配屏幕大小
- 表格可横向滚动查看完整信息

## 🔄 数据刷新

- **自动刷新**：完成任何操作后自动刷新列表和统计
- **手动刷新**：点击"查询"按钮或按F5刷新页面

## 📞 常见问题

### Q1: 为什么看不到"确认"按钮？
**A**: 只有"待处理"状态的订单才显示"确认"按钮

### Q2: 如何修改已分配的服务人员？
**A**: 点击"分配"按钮，重新选择服务人员即可

### Q3: 订单可以删除吗？
**A**: 可以，但建议使用"取消"功能而不是删除，以保留记录

### Q4: 如何查看用户评价？
**A**: 点击查看按钮，在详情中可以看到评分和评价内容（已评价的订单）

### Q5: 导出功能在哪里？
**A**: 点击"导出数据"按钮（功能开发中）

## 🎓 最佳实践

1. **及时处理**：每天至少检查2次待处理订单
2. **合理分配**：根据服务人员的工作量和擅长领域分配
3. **详细备注**：重要订单在取消或完成时添加详细备注
4. **定期检查**：每周查看已完成订单，总结服务质量
5. **关注评价**：及时查看用户评价，改进服务

## 🚀 工作流程建议

### 日常工作流程
```
早上9:00
├─ 查看统计数据，了解整体情况
├─ 处理所有待处理订单
│  ├─ 确认订单
│  └─ 分配服务人员
├─ 检查进行中订单，跟进进度
└─ 处理用户反馈和投诉

下午3:00
├─ 再次检查待处理订单
├─ 完成已完成的服务订单
└─ 查看用户评价

下班前
├─ 确保当天所有订单都已处理
├─ 检查明天的预约订单
└─ 准备第二天的工作安排
```

## 📊 统计数据解读

| 统计项 | 含义 | 建议 |
|-------|------|------|
| 总预约数 | 累计所有订单 | 关注增长趋势 |
| 待处理 | 需要立即处理 | 保持在低位 |
| 已确认 | 等待服务 | 及时分配人员 |
| 进行中 | 正在服务 | 跟进服务质量 |
| 已完成 | 服务完成 | 查看用户评价 |
| 已取消 | 取消的订单 | 分析取消原因 |
